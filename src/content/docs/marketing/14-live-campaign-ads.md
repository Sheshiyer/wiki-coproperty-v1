## DYNAMIC TOKENS SYSTEM

**Usage:** Replace bracketed tokens with real-time campaign data

**Available Tokens:**
- `{SLOTS_REMAINING}` = Partnership slots still available (e.g., "7", "3", "LAST 2")
- `{PARTNERSHIPS}` = Total partnerships confirmed (e.g., "31", "47")
- `{OCCUPANCY_AVG}` = Portfolio average occupancy (e.g., "77.4%", "78.1%")
- `{PROPERTIES_MANAGED}` = Total properties under management (e.g., "53", "64")
- `{DEADLINE}` = Campaign end date/time (e.g., "Friday midnight", "72 hours")
- `{RECENT_PARTNER}` = Latest partnership city/demographic (e.g., "Singapore investor", "Bangkok portfolio owner")

**Example Implementation:**
```
Headline: "{SLOTS_REMAINING} Partnership Slots Remain for 2025. Calculate Your Revenue Gap."
→ Renders as: "7 Partnership Slots Remain for 2025. Calculate Your Revenue Gap."
```
